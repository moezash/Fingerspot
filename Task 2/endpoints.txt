Fingerspot Cloud API Endpoints
Base URL: https://developer.fingerspot.io

1. Get Device List
   Endpoint: /api/get_device
   Method: POST
   Description: Retrieves a list of all devices registered to the account.

2. Get Attendance Logs
   Endpoint: /api/get_attlog
   Method: POST
   Description: Retrieves attendance scan records from a specific device within a date range.

3. Set User Information
   Endpoint: /api/set_userinfo
   Method: POST
   Description: Uploads or updates user data (name, PIN, privilege, templates) to the device.

4. Get User Information
   Endpoint: /api/get_userinfo
   Method: POST
   Description: Requests specific user data from the device. Result is typically sent via Webhook.

5. Delete User Information
   Endpoint: /api/delete_userinfo
   Method: POST
   Description: Removes a user from the device by their PIN.

6. Remote Registration
   Endpoint: /api/reg_online
   Method: POST
   Description: Triggers the machine to enter registration mode for a specific user and template type.

7. Sync Time
   Endpoint: /api/set_time
   Method: POST
   Description: Synchronizes the device's date and time with the server or a specified value.

8. Restart Machine
   Endpoint: /api/restart
   Method: POST
   Description: Sends a command to remotely reboot the attendance machine.

Note: All requests require a Bearer Token in the Authorization header and 'Content-Type: application/json'. Most commands are asynchronous and results are delivered via Webhook.
