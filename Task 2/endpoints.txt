Fingerspot Cloud API Main Endpoints
Base URL: https://developer.fingerspot.io

1. Get Device List
   - Endpoint: /api/get_device
   - Method: POST
   - Description: Retrieve a list of all devices registered in the account.

2. Get Attendance Logs
   - Endpoint: /api/get_attlog
   - Method: POST
   - Description: Retrieve attendance scan logs from a device within a specific date range.

3. Get User Info
   - Endpoint: /api/get_userinfo
   - Method: POST
   - Description: Request user information (PIN, name, templates) from the device. Asynchronous; results sent via Webhook.

4. Set User Info
   - Endpoint: /api/set_userinfo
   - Method: POST
   - Description: Upload or update user information and templates to the device.

5. Delete User Info
   - Endpoint: /api/delete_userinfo
   - Method: POST
   - Description: Delete a specific user from the device using their PIN.

6. Register Online
   - Endpoint: /api/reg_online
   - Method: POST
   - Description: Trigger the device to enter registration mode for a specific user and template type.

7. Set Time
   - Endpoint: /api/set_time
   - Method: POST
   - Description: Synchronize the device's time and timezone with the server.

8. Restart Device
   - Endpoint: /api/restart
   - Method: POST
   - Description: Remotely reboot the attendance machine.
