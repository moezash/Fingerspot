Fingerspot Cloud API - Main Endpoints List
Base URL: https://developer.fingerspot.io

1. Get Device List
   Endpoint: /api/get_device
   Method: POST
   Description: Retrieves a list of all attendance machines registered to the account.

2. Get Attendance Logs
   Endpoint: /api/get_attlog
   Method: POST
   Description: Fetches scan data (attendance logs) from a specific device within a date range.

3. Set User Information (Add/Update Employee)
   Endpoint: /api/set_userinfo
   Method: POST
   Description: Sends employee profile data (PIN, Name, Password, RFID, Templates) to the device.

4. Get User Information
   Endpoint: /api/get_userinfo
   Method: POST
   Description: Requests employee profile data from the device. Results are sent asynchronously via Webhook.

5. Delete User Information
   Endpoint: /api/delete_userinfo
   Method: POST
   Description: Removes an employee profile from the device.

6. Remote Registration
   Endpoint: /api/reg_online
   Method: POST
   Description: Commands the machine to enter registration mode for a specific user and template type.

7. Set Device Time
   Endpoint: /api/set_time
   Method: POST
   Description: Synchronizes the device clock or sets a specific timezone.

8. Restart Device
   Endpoint: /api/restart
   Method: POST
   Description: Remotely reboots the attendance machine.

Note: All requests require an 'Authorization: Bearer <token>' header and should use 'Content-Type: application/json'.
