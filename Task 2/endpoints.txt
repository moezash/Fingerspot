Fingerspot Cloud API Main Endpoints
==================================

All requests use POST method and JSON body.

1. Get Device List
   Endpoint: /api/get_device
   Description: Retrieve all registered attendance machines.

2. Get Attendance Logs
   Endpoint: /api/get_attlog
   Description: Fetch scan data from a specific device within a date range.

3. Get User Information
   Endpoint: /api/get_userinfo
   Description: Request user details (PIN, name, templates) from device (Asynchronous).

4. Set User Information
   Endpoint: /api/set_userinfo
   Description: Upload or update user data (PIN, name, templates) to the device.

5. Delete User Information
   Endpoint: /api/delete_userinfo
   Description: Remove a specific user from the attendance machine.

6. Remote Registration
   Endpoint: /api/reg_online
   Description: Trigger online registration mode on the device for various templates.

7. Sync Time
   Endpoint: /api/set_time
   Description: Synchronize device date, time, and timezone.

8. Restart Machine
   Endpoint: /api/restart
   Description: Remotely reboot the attendance machine.
