Main Fingerspot Cloud API Endpoints:

1. Get Device List
   Endpoint: /api/get_device
   Method: POST
   Description: Retrieves a list of all devices registered in the account.

2. Get Attendance Logs
   Endpoint: /api/get_attlog
   Method: POST
   Description: Fetches attendance scan data within a specific date range.

3. Set User Information
   Endpoint: /api/set_userinfo
   Method: POST
   Description: Uploads user/employee data (PIN, Name, Templates) to the device.

4. Get User Information
   Endpoint: /api/get_userinfo
   Method: POST
   Description: Requests user information from the device (asynchronous, results via Webhook).

5. Delete User Information
   Endpoint: /api/delete_userinfo
   Method: POST
   Description: Deletes a specific user from the device.

6. Remote Registration
   Endpoint: /api/reg_online
   Method: POST
   Description: Triggers the machine to enter registration mode for a specific user and template type.

7. Set Time
   Endpoint: /api/set_time
   Method: POST
   Description: Synchronizes the machine's time and timezone.

8. Restart Machine
   Endpoint: /api/restart
   Method: POST
   Description: Remotely reboots the attendance machine system.
