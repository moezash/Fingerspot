Fingerspot Cloud API Main Endpoints
====================================

Base URL: https://developer.fingerspot.io

1. Get Device List
   Endpoint: /api/get_device
   Method: POST
   Description: Retrieve the list of all registered attendance machines.

2. Get Attendance Logs
   Endpoint: /api/get_attlog
   Method: POST
   Description: Fetch scan logs from a specific device within a date range (max 2 days recommended).

3. Set User Info (Add/Update Employee)
   Endpoint: /api/set_userinfo
   Method: POST
   Description: Send user data (PIN, Name, Password, Card, etc.) to the device.

4. Get User Info
   Endpoint: /api/get_userinfo
   Method: POST
   Description: Request user data from the device. Result is usually sent back via Webhook.

5. Delete User Info
   Endpoint: /api/delete_userinfo
   Method: POST
   Description: Remove a specific user from the device by PIN.

6. Register Online
   Endpoint: /api/reg_online
   Method: POST
   Description: Trigger the device to enter registration mode for fingerprints, face, etc.

7. Set Time
   Endpoint: /api/set_time
   Method: POST
   Description: Synchronize the device's date and time or change timezone.

8. Restart Machine
   Endpoint: /api/restart
   Method: POST
   Description: Remotely reboot the attendance machine.

Authentication:
All requests require an 'Authorization: Bearer <TOKEN>' header.
Most requests also require 'trans_id' and 'cloud_id' in the JSON body.
