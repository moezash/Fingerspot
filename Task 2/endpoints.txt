Fingerspot Cloud API Main Endpoints
----------------------------------

1. Get Device List
   Endpoint: https://developer.fingerspot.io/api/get_device
   Method: POST
   Description: Retrieve all registered attendance machines under your account.

2. Get Attendance Logs
   Endpoint: https://developer.fingerspot.io/api/get_attlog
   Method: POST
   Description: Retrieve scan logs (pin, scan time, status) from a device within a date range.

3. Set User Information
   Endpoint: https://developer.fingerspot.io/api/set_userinfo
   Method: POST
   Description: Add or update employee information (PIN, Name, Privilege) on the device.

4. Get User Information
   Endpoint: https://developer.fingerspot.io/api/get_userinfo
   Method: POST
   Description: Request user details from the machine. The result is sent via Webhook.

5. Delete User Information
   Endpoint: https://developer.fingerspot.io/api/delete_userinfo
   Method: POST
   Description: Remote deletion of a user/employee from the attendance machine.

6. Remote Registration
   Endpoint: https://developer.fingerspot.io/api/reg_online
   Method: POST
   Description: Trigger the machine to enter registration mode for face/fingerprint/card.

7. Sync Machine Time
   Endpoint: https://developer.fingerspot.io/api/set_time
   Method: POST
   Description: Synchronize the attendance machine's time with a specified timezone.

8. Restart Machine
   Endpoint: https://developer.fingerspot.io/api/restart
   Method: POST
   Description: Trigger a remote system reboot of the attendance machine.

Note: All requests require 'Authorization: Bearer [TOKEN]' and 'Content-Type: application/json' headers.
Most requests also require 'trans_id' and 'cloud_id' in the JSON body.
