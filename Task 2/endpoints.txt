Fingerspot Cloud API - Main Endpoints

1. Get Device List
   Endpoint: /api/get_device
   Method: POST
   Description: Retrieves a list of all registered devices in the account.

2. Get Attendance Logs
   Endpoint: /api/get_attlog
   Method: POST
   Description: Fetches attendance scan logs from a specific device within a date range.

3. Get User Information
   Endpoint: /api/get_userinfo
   Method: POST
   Description: Requests user information (PIN, name, templates) from a specific device. Result is sent via Webhook.

4. Set User Information
   Endpoint: /api/set_userinfo
   Method: POST
   Description: Adds or updates user information (PIN, name, templates) on a specific device.

5. Delete User Information
   Endpoint: /api/delete_userinfo
   Method: POST
   Description: Removes a specific user from an attendance device.

6. Online Registration
   Endpoint: /api/reg_online
   Method: POST
   Description: Triggers the device to enter registration mode for a specific user and template type.

7. Sync Time
   Endpoint: /api/set_time
   Method: POST
   Description: Synchronizes the device clock with the server time or a specific timezone.

8. Restart Machine
   Endpoint: /api/restart
   Method: POST
   Description: Sends a command to remotely reboot the attendance machine.
