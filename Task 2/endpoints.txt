Fingerspot Cloud API Endpoints List

1. Get Device List
   Endpoint: /api/get_device
   Method: POST
   Description: Retrieve a list of all attendance devices registered in the account.

2. Get Attendance Logs
   Endpoint: /api/get_attlog
   Method: POST
   Description: Retrieve scan logs from a specific device within a specified date range.

3. Add/Update User Information
   Endpoint: /api/set_userinfo
   Method: POST
   Description: Send user data (PIN, Name, Privilege, etc.) to a specific device.

4. Get User Information
   Endpoint: /api/get_userinfo
   Method: POST
   Description: Request user details from a specific device. Results are usually returned via Webhook.

5. Delete User Information
   Endpoint: /api/delete_userinfo
   Method: POST
   Description: Delete a specific user from a device based on their PIN.

6. Remote Registration
   Endpoint: /api/reg_online
   Method: POST
   Description: Trigger the device to enter registration mode for a specific user.

7. Sync Time
   Endpoint: /api/set_time
   Method: POST
   Description: Synchronize the device's date and time.

8. Restart Device
   Endpoint: /api/restart
   Method: POST
   Description: Remotely reboot the attendance machine.
