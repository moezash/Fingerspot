Fingerspot Cloud API Main Endpoints
====================================

1. Get Device List
   Endpoint: https://developer.fingerspot.io/api/get_device
   Method: POST
   Description: Retrieve all registered devices in the account.

2. Get Attendance Logs
   Endpoint: https://developer.fingerspot.io/api/get_attlog
   Method: POST
   Description: Retrieve attendance scan logs from a specific device within a date range.

3. Set User Info (Add/Update Employee)
   Endpoint: https://developer.fingerspot.io/api/set_userinfo
   Method: POST
   Description: Upload or update employee information (name, PIN, etc.) to the device.

4. Get User Info
   Endpoint: https://developer.fingerspot.io/api/get_userinfo
   Method: POST
   Description: Request employee information from the device (returns data via Webhook).

5. Delete User Info
   Endpoint: https://developer.fingerspot.io/api/delete_userinfo
   Method: POST
   Description: Remove an employee from the device.

6. Register Online (Remote Enrollment)
   Endpoint: https://developer.fingerspot.io/api/reg_online
   Method: POST
   Description: Trigger the device to enter registration mode for a specific user and template type.

7. Set Time (Sync Time)
   Endpoint: https://developer.fingerspot.io/api/set_time
   Method: POST
   Description: Synchronize the device's date and time.

8. Restart Machine
   Endpoint: https://developer.fingerspot.io/api/restart
   Method: POST
   Description: Reboot the device remotely.

Note: All requests require 'Authorization: Bearer [TOKEN]' and 'Content-Type: application/json' headers.
Most commands are asynchronous and results are sent back via Webhook.
