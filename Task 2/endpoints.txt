Fingerspot Cloud API - Main Endpoints List
Base URL: https://developer.fingerspot.io

1. Get Device List
   Endpoint: /api/get_device
   Method: POST
   Description: Retrieves a list of all attendance machines registered under your Fingerspot Cloud account.

2. Get Attendance Logs
   Endpoint: /api/get_attlog
   Method: POST
   Description: Fetches scan data (attendance logs) from a specific device.
   Note: Usually limited to a maximum date range of 2 days per request.

3. Set User Information
   Endpoint: /api/set_userinfo
   Method: POST
   Description: Uploads or updates employee data (PIN, Name, Privilege, Password, etc.) to a specific device.

4. Get User Information
   Endpoint: /api/get_userinfo
   Method: POST
   Description: Requests user details from a device.
   Note: This is an asynchronous command; the machine will send the data back to your configured Webhook.

5. Delete User Information
   Endpoint: /api/delete_userinfo
   Method: POST
   Description: Remotely deletes an employee's record from a specific attendance machine.

6. Register Online
   Endpoint: /api/reg_online
   Method: POST
   Description: Triggers the machine to enter remote registration mode for a specific user and template type (e.g., finger, face).

7. Set Device Time
   Endpoint: /api/set_time
   Method: POST
   Description: Synchronizes the attendance machine's date and time with the server/cloud.

8. Restart Machine
   Endpoint: /api/restart
   Method: POST
   Description: Sends a remote command to restart the attendance machine system.

Webhook Integration (Push Data):
- Real-time Attendance Scan: Automatically pushed to your URL when a user scans.
- Asynchronous Command Responses: Returns results for Get Userinfo, Set Userinfo, and other remote commands.
